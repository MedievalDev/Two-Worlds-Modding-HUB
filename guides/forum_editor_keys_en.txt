Two Worlds Editor - the controls
================================

Source: the "Howto: Two Worlds Editor Controls" thread by stevesmith in the
Tutorials and Howto's forum of InsideTwoWorlds (2007), read from the Internet
Archive. Rewritten and sorted.

Everywhere
----------
  Tab            switches between the tool sets
  F1             terrain shape and textures
  F2             liquid pools
  F3             colours
  F4             objects
  F5 / F6 / F7 / F8    time of day 64 / 128 / 192 / 0
  F9 / F10       time of day one step back / forward
  F11            show only the selected textures
  Alt            mouse pointer on or off
  arrow keys     move across the map
  left click     act with the current tool
  right click    rotate the camera (inverted)
  Insert / Delete      rotate left / right
  Page Up / Page Down  zoom out / in
  wheel forward / back zoom out / in
  wheel click    move across the map

Terrain shape and textures (F1)
-------------------------------
  left click     apply
  1 - 10         size and shape of the brush

Objects (F4), with Num Lock on
------------------------------
  5              select the object
  4 / 6          rotate around y
  2 / 8          rotate around z
  * / /          rotate around x
  1 / 3          move along y
  7 / 9          move along x
  + / -          raise / lower
  Del (.)        delete the object

The console of the editor opens with C. What the commands do is in the
editor beginner guide.
